## :information_source: About

📄 A full-stack to-do list: a React frontend with Redux (thunk, promise and multi middlewares) to add, search, complete, reopen and remove tasks, and a REST API with Node.js, Express and MongoDB (Mongoose, generated with node-restful).

Built in 2021 for training.

## :arrow_forward: Run

You need [Node.js](https://nodejs.org/) and MongoDB running on `localhost`.

### Backend

In the [`backend/`](backend/) folder:

```bash
npm install
npm run dev
```

> The API starts at <http://localhost:3003>.

### Frontend

In the [`frontend/`](frontend/) folder:

```bash
yarn
yarn start
```

> The app opens at <http://localhost:3000>.
